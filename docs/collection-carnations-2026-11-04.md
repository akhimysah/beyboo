# Collection : nouvelles carnations et coiffures

Quatre portraits supplémentaires répondent à la demande de représentation des communautés noires et latines. Les choix du site sont nommés par couleur de matière, sans attribuer une apparence unique à une communauté. Les personnalités, histoires, vêtements et yeux restent les mêmes. Les versions précédentes restent sélectionnables.

- Izan : brun, cheveux noirs crépus ; variante ivoire conservée.
- Sana : brun profond, tresse noire texturée ; variante ivoire conservée.
- Rayan : brun doré, cheveux bruns ondulés ; variante ivoire conservée.
- Léa : brun clair, deux couettes châtain ; variante ivoire avec deux couettes blondes conservée.

Assets : `dist/assets/studio/izan-brun.webp`, `sana-brun-profond.webp`, `rayan-brun-dore.webp`, `lea-brun-clair.webp`.

Les nouveaux portraits apparaissent par défaut dans la collection. La fiche et le configurateur permettent de choisir la carnation ; les cartes, images et récapitulatif suivent le choix. La sauvegarde existante conserve désormais ce choix. Les visuels des campagnes sont des scènes de conception fixes et n'ont pas été régénérés.

Validation : syntaxe JavaScript, chargement des quatre images, changement de carnation dans la fiche, transfert au configurateur, sauvegarde puis rechargement, récapitulatif, écran seul sans choix de peluche. Les corps restent immobiles.

Mode de génération : outil image natif, édition des portraits de référence, conversion WebP pour le site. Prompts ci-dessous.
